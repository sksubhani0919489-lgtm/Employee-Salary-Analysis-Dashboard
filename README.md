# Employee Salary Analysis Dashboard

## Project Overview

This project analyzes employee salary data using Microsoft Excel to identify salary patterns, department-wise salary distribution, and key business insights.

The project includes data preparation, summary analysis, KPI calculations, department-wise analysis, and an interactive Excel dashboard.

## Tools & Skills

- Microsoft Excel
- Data Cleaning & Preparation
- Excel Formulas
- KPI Analysis
- Department-wise Analysis
- Data Visualization
- Dashboard Development
- Business Insights

## Key Analysis

- Total Salary
- Average Salary
- Highest Salary
- Lowest Salary
- Employee Count
- Department-wise Total Salary
- Department-wise Average Salary

## Dashboard

The Excel dashboard provides a visual summary of employee salary performance using KPI cards, charts, department-wise analysis, and business insights.

## Project Structure

- `Employee_Salary_Analysis_Dashboard.xlsx` — Complete Excel analysis and dashboard

## Key Business Insights

- IT has the highest total salary.
- IT has the highest average salary.
- Department-wise salary comparison helps identify salary distribution patterns.

## Outcome

This project demonstrates practical skills in Microsoft Excel, data analysis, visualization, dashboard creation, and communicating business insights from structured data.
